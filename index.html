怎么获取 Token（约 1 分钟）
  1. 点下面的按钮打开 GitHub 的 Token 创建页面。没登录的话，先登录你自己的 GitHub 账号。
  2. Note 随便填，比如 ghrank；Expiration 选 90 days。
  3. 权限（Select scopes）一个都不要勾。本页面只读取公开仓库，不需要任何权限。
  4. 拉到页面最下面，点绿色的 Generate token。
  5. 页面会显示一串以 ghp_ 开头的字符，立即复制（关掉页面后就看不到了）。
  6. 回到本页面，粘贴到上面的输入框，点「保存」。

    关于本排行榜

    它把 GitHub 上星标数较高的开源仓库按时间范围（近 7 天、近 30 天、近 1 年）整理成排行榜，并单独提供「总榜」：全站按星标降序的前 500 个仓库，并提供语言分布、今日增量、活跃度、热门开发者与组织等视图。

    页面默认读取定时抓取的静态数据，每 3 小时更新一次；数据来自 GitHub 公开的 Search API。「总榜」是 GitHub 全站按星标降序的前 500 名（深翻 10 页搜索结果），近 7 天 / 30 天 / 1 年三个榜只收该时间段内新建的仓库。筛选条件会写进网址（例如 ?range=month&lang=Python&sort=trend），复制地址栏即可分享同一视图。

    数据是怎么取的（技术细节）

    抓取规则：每个榜单条件按星标区间分段、分页查询（只取星标数超过 50 的仓库），合并去重后最多取前 500 个；结果在浏览器里缓存 2 小时，避免重复请求。

    口径：「今日增量」是与至少 1 小时前的一次记录对比得出的星标涨数；「新晋 / 掉队」是同一对比里新进榜与掉出榜的项目。开发者榜与组织榜取粉丝数超过 1000 的前 50 个账号。
