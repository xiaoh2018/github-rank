GitHub 热门项目排行榜

按星标数排序。"近 N 天"指创建时间在此之后的新项目，用来发现新火起来的仓库。

小白指南：怎么获取 Token（约 1 分钟，可选）

Token 是 GitHub 发给你的一串密码，填进来后可以「立即刷新」。不填也能正常看榜单。

  1. 点下面的按钮打开 GitHub 的 Token 创建页面。没登录的话，先登录你自己的 GitHub 账号。
  2. Note 随便填，比如 ghrank；Expiration 选 90 days。
  3. 权限（Select scopes）一个都不要勾。本页面只读取公开仓库，不需要任何权限。
  4. 拉到页面最下面，点绿色的 Generate token。
  5. 页面会显示一串以 ghp_ 开头的字符，立即复制（关掉页面后就看不到了）。
  6. 回到本页面，粘贴到上面的输入框，点「保存」。
打开 GitHub 创建 Token 页面 ↗

Token 只保存在你自己的浏览器里，不会上传到别处。如果泄露了，到 GitHub 的 Token 设置页删除即可。

Token 只在点击「立即刷新」时使用，可把搜索额度从每分钟 10 次提到 30 次；默认数据来自定时抓取的静态文件（每 3 小时更新），不消耗额度。Token 只保存在本机 localStorage 中，不会上传到别处。

    关于本排行榜

    这个榜单是什么？

    它把 GitHub 上星标数较高的开源仓库按时间范围（近 7 天、近 30 天、近 1 年、全部）整理成排行榜，并提供语言分布、今日增量、活跃度、热门开发者与组织等视图。

    数据多久更新一次？

    页面默认读取定时抓取的静态数据，每 3 小时更新一次；数据来自 GitHub 公开的 Search API。

    如何分享当前筛选结果？

    筛选条件会写进网址（例如 ?range=month&lang=Python&sort=trend），复制地址栏即可分享同一视图。

    数据来自 GitHub Search API：每个条件按星标区间分段、分页查询（星标数超过 50 的仓库），合并去重后最多取前 500 个，结果在浏览器中缓存 2 小时。今日增量和新晋 / 掉队是和至少 1 小时前的一次记录对比得出的。开发者榜与组织榜取粉丝数超过 1000 的前 50 个账号。筛选条件会保存在网址里，方便分享。
